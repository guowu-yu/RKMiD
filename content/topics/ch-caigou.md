## 一、概念与定位

项目采购管理是"从外部获取产品/服务"的过程。软考中，**合同类型的风险归属与适用场景是上午单选必考**（约占 2–3 分），自制或外购分析、招标方式也常考。重点掌握：四过程、Make-or-Buy、三类合同（总价/成本补偿/工料）的风险分担。

## 二、核心知识

### （一）采购四过程

| 过程 | 关键活动 | 主要输出 |
|---|---|---|
| 规划采购管理 | 自制外购分析、合同类型选择、采购文件 | 采购管理计划、采购文件 |
| 实施采购 | 招标、投标、评标、签合同 | 选定的卖方、合同 |
| 控制采购 | 履约监督、变更、索赔 | 工作绩效、变更请求 |
| 结束采购 | 验收、结算、归档 |  closed 合同、经验教训 |

### （二）自制或外购（Make-or-Buy）

比较"自制成本"与"外购成本+管理费"，并考虑：核心竞争力、自有产能、风险、保密性、交付速度。结论写入采购管理计划。

### （三）合同类型与风险归属（必考）

| 类型 | 子类 | 风险承担 | 适用场景 |
|---|---|---|---|
| 总价 FFP/FPIF/FP-EPA | 固定总价 FFP | 卖方 | 范围明确、最确定 |
| | 总价加激励 FPIF | 共担（设价格上限） | 范围较明确 |
| | FP-EPA | 卖方（通胀保护） | 长期合同 |
| 成本补偿 CPFF/CPIF/CPAF | 成本+固定费 CPFF | 买方 | 范围不清、鼓励控本 |
| | 成本+激励费 CPIF | 共担 | 共担风险 |
| | 成本+奖励费 CPAF | 买方（主观评价） | 绩效难量化 |
| 工料 T&M | — | 混合 | 量不确定、短期、增援 |

**规律**：范围越明确，越宜总价（风险给卖方）；范围越模糊，越宜成本补偿（风险给买方）；工料兼具二者特征。

## 三、方法/流程

招标方式：公开招标（不特定对象，最规范）、邀请招标（3 家以上特定对象）。评标常用最低评标价法或综合评分法。合同授予应满足：合规、技术达标、价格合理。

## 四、记忆口诀/易错点

- **类型口诀**："范围明→总价(卖方险)；范围糊→成本补偿(买方险)；量不定→工料(混合险)"。
- **易错**：CPFF 中买方承担成本超支风险，但固定费用不随成本变，故激励卖方控本。
- **易错**：CPPC（成本+百分比费用）最不受欢迎——卖方成本越高费用越高，鼓励超支，考试中一般选它作为"反面典型"。
- **易错**：工料合同本质更接近成本补偿，但有单价封顶，常用于补充人力。

## 五、真题自测

1. 范围高度不确定、技术复杂的研发外包，宜选（ ）。
   A. 固定总价 FFP  B. 成本补偿 CPFF  C. 工料 T&M  D. FP-EPA

2. 下列哪类合同最可能导致卖方"故意超支"？（ ）
   A. FFP  B. CPFF  C. CPPC（成本+百分比）  D. FPIF

3. 自制或外购分析时，除成本外还应考虑（ ）。
   A. 仅价格  B. 核心竞争力与产能  C. 仅工期  D. 仅质量

> **参考答案**：1.B；2.C；3.B。
