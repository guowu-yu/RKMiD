## 一、概念与定位

**可行性研究**是立项阶段的核心论证工作，回答"项目是否值得做"。在软考中属第 2 章重点，上午选择考概念与指标判据，下午案例常要求"补充遗漏的可研维度"或"计算 NPV/回收期"。

## 二、核心知识：六大维度

| 维度 | 论证内容 |
|---|---|
| 技术可行性 | 技术路线成熟度、复杂度、资源（人员/设备）可得性 |
| 经济可行性 | 成本收益分析、资金筹措、盈利能力（重点） |
| 运行环境可行性 | 组织文化、人员素质、制度流程是否匹配 |
| 法律可行性 | 合规、知识产权归属、合同与政策风险 |
| 社会可行性 | 社会接受度、环境影响、就业等 |
| 风险可行性 | 识别主要风险并评估应对可行性 |

## 三、经济评价指标（必考计算）

| 指标 | 公式/含义 | 判据 |
|---|---|---|
| 净现值 NPV | \( NPV=\sum \frac{CF_t}{(1+i)^t}-I_0 \) | NPV ≥ 0 可行 |
| 内部收益率 IRR | 使 NPV = 0 的贴现率 i | IRR ≥ 基准收益率可行 |
| 投资回收期 Pt | 累计净现金流由负转正的年限 | 越短越好（≤ 基准回收期） |
| 投资收益率 | 年均净收益 / 投资额 | 越高越好 |
| 盈亏平衡点 BEP | 收入=总成本时的产销量 | 越低抗风险能力越强 |

**决策逻辑**：当 **NPV ≥ 0 且 IRR ≥ 基准收益率** 时，项目经济上可行；BEP 越低，项目抗市场波动能力越强，风险越小。

## 四、研究步骤（流程）

机会研究 → 初步可研 → 详细可研（含上述六维度论证）→ 出具**可行性研究报告** → 项目评估与决策。报告与**项目建议书**不同：建议书侧重"要不要立"（粗），可研报告侧重"能不能做、值不值"（细），是立项核心文档。

## 五、记忆口诀与易错点

- **口诀**：六维度"技经运法社风"；判据"NPV≥0、IRR≥基准"。
- **易错**：① NPV 与 IRR 结论在非常规现金流下可能冲突，考试一般默认一致；② 投资回收期未考虑资金时间价值（静态），且忽略回收期后收益；③ BEP 是"点"不是"区间"。

## 六、真题自测

1. （单选）某项目 NPV = 50 万，基准收益率 8%，IRR = 10%，则？ A. 不可行 B. 可行 C. 无法确定 D. 需重算
2. （填空）使 NPV = 0 的贴现率称为 ______。
3. （判断）盈亏平衡点越低，项目抗风险能力越弱。（ ）

> **参考答案**：1. B（NPV≥0 且 IRR≥基准收益率，可行）；2. 内部收益率（IRR）；3. ×（BEP 越低抗风险越强）。
