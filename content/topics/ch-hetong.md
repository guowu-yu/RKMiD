## 一、概念与定位

合同管理是"确保合同各方履约并妥善处理变更与争议"的过程，是采购管理的落地环节。软考中，**合同变更须书面、索赔时效 28 天、主体不得分包/禁止转包**是上午单选与下午找错的高频点。重点掌握：合同要素、变更原则、索赔流程、分包规则。

## 二、核心知识

### （一）合同主要要素（六要素）

| 要素 | 说明 |
|---|---|
| 标的 | 合同对象（货物/服务/工程） |
| 数量与质量 | 交付规模与标准 |
| 价款或报酬 | 金额、支付方式 |
| 履行期限/地点/方式 | 何时何地如何交付 |
| 违约责任 | 逾期、不符的罚则 |
| 争议解决 | 协商/调解/仲裁/诉讼 |

### （二）合同生命周期

拟定 → 签订 → 履行 → 变更 → 终止/收尾（验收、结算、资料归档）。

### （三）合同变更

- 必须**书面**、双方协商一致。
- 重大变更可能影响招投标结果，须重新评估，必要时重新招标。
- 变更须走整体变更控制，更新合同与配置。

### （四）索赔管理

**流程**：事态调查 → 在规定时限内发出**索赔通知** → 提交**索赔报告**（证据、计算）→ 对方答复/反索赔 → 协商/调解/仲裁/诉讼。

**索赔成立要件**：① 合法有效的合同；② 存在实际损失；③ 损失与违约有因果关系；④ 在时效内提出。

> 通用惯例：索赔意向/通知通常在事件发生后 **28 天**内提出。

### （五）分包与转包规则

- 分包须**经发包人同意**。
- **主体工程不得分包**。
- **禁止转包**（将全部工程转给他人）。
- 违法分包/转包须承担法律责任。

## 三、方法/流程

合同控制流程：监督履约 → 发现偏差 → 评估变更/索赔 → 书面确认 → 执行 → 验收结算。索赔须"及时书面通知 + 充分证据"，逾期或口头主张通常不被支持。

## 四、记忆口诀/易错点

- **变更口诀**："合同变更三要素：书面、协商、走流程；口头无效莫轻信"。
- **索赔口诀**："二十八天要通知，证据报告不能少；主体不分包、转包要坐牢"。
- **易错**：合同变更"口头同意"无效，必须书面。
- **易错**：索赔时效 28 天是常考数字，但不是所有合同都一致，以合同约定为准，重点掌握"须在约定时效内书面通知"。
- **易错**：主体工程不得分包≠不能分包，非主体、非关键工作经同意可分包。

## 五、真题自测

1. 关于合同变更，正确的是（ ）。
   A. 口头同意即可  B. 必须书面并协商一致  C. 仅买方可提  D. 无须走变更流程

2. 下列哪种做法违反法律规定？（ ）
   A. 经发包人同意分包非主体工程  B. 将主体工程分包  C. 提交索赔报告  D. 书面变更合同

3. 索赔成立要件不包括（ ）。
   A. 有效合同  B. 实际损失  C. 因果关系  D. 买方主观不满意

> **参考答案**：1.B；2.B（主体工程不得分包）；3.D。
