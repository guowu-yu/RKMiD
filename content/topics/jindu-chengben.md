## 一、进度管理概览

进度管理过程：规划进度管理 → 定义活动 → 排列活动顺序 → 估算活动资源/历时 → **制定进度计划** → 控制进度。计算核心在"制定进度计划"（网络图、关键路径）与"控制进度"（挣值）。

---

## 二、网络图与关键路径（CPM）

详见子专题[网络图与关键路径](jc-wangluotu.html)。

- **节点/箭线**：前导图法（PDM，活动在节点）最常用；依赖关系 FS（完成-开始）为主。
- **关键路径**：总工期最长的路径；其上的活动为**关键活动**（总浮动时间 = 0）。
- **最早开始/结束（ES/EF）**：正向推算；**最晚开始/结束（LS/LF）**：反向推算。
- **总浮动 TF** = LS − ES = LF − EF；**自由浮动 FF** = 后续 ES 最小值 − 本活动 EF。

> **必考题型**：给活动依赖与历时，求（1）关键路径与总工期；（2）某活动的总浮动/自由浮动；（3）某活动延误对总工期的影响。

## 三、PERT 三点估算

详见子专题[关键路径与 PERT](jc-guanjianlujing.html)。

- 期望历时 `te = (O + 4M + P) / 6`
- 标准差 `σ = (P − O) / 6`；方差 `σ²`
- 多活动路径总期望 = 各期望之和；总标准差 = √(各方差之和)
- 可用正态分布估算"在 X 天内完成的概率"

## 四、进度压缩

- **赶工（Crashing）**：增加资源/加班缩短关键活动，通常增成本；选"成本斜率最小"的关键活动赶工。
- **快速跟进（Fast Tracking）**：并行原串行活动，增风险与返工。

## 五、成本管理与挣值（EVM，必考中的必考）

详见子专题[挣值管理 EVM](jc-zhiying.html)。三个基本参数：

| 参数 | 含义 | 计算 |
|---|---|---|
| PV | 计划价值（计划应完成工作的预算） | 按计划 |
| EV | 挣值（实际完成工作的预算） | 实际完成% × 预算 |
| AC | 实际成本（实际花费） | 实际支出 |

**偏差与指数**：

- 进度偏差 `SV = EV − PV`；成本偏差 `CV = EV − AC`
- 进度绩效 `SPI = EV / PV`；成本绩效 `CPI = EV / AC`
- SV>0/SPI>1 领先；CV>0/CPI>1 节约

**完工预测**（预测 EAC）：

- 典型偏差持续：`EAC = BAC / CPI`
- 非典型（未来按预算）：`EAC = AC + (BAC − EV)`
- 既超支又进度滞后：`EAC = AC + (BAC − EV)/(CPI × SPI)`
- 完工尚需 `ETC = EAC − AC`；完工偏差 `VAC = BAC − EAC`

> **易错点**：CV/CPI 看成本，SV/SPI 看进度，二者不可混；"ETC 按当前绩效"用 `ETC = (BAC−EV)/CPI`。务必先算 PV/EV/AC 三值再套公式。
