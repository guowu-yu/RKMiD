## 一、进度与成本管理概览

进度管理过程：规划进度管理 → 定义活动 → 排列活动顺序 → 估算活动资源/历时 → **制定进度计划** → 控制进度。成本管理：规划成本 → 估算成本 → 制定预算 → **控制成本**。计算核心在"制定进度计划"（网络图、关键路径）与"控制成本/进度"（挣值 EVM）。

## 二、四大计算板块

1. **网络图与关键路径（CPM）**：前导图 PDM、正推求 ES/EF、逆推求 LS/LF、总浮动 TF 与自由浮动 FF。
2. **PERT 三点估算**：\(te = (O + 4M + P)/6\)，路径总期望 = 各期望之和，总标准差 = \(\sqrt{\sum \sigma^2}\)。
3. **进度压缩**：赶工（加成本换时间）、快速跟进（并行换风险）。
4. **挣值管理 EVM**：PV/EV/AC 三值 + 偏差/指数 + 完工预测 EAC/ETC/VAC。

## 三、综合例题（EVM 入门）

某项目 \(BAC = 100\) 万元。第 10 天检查时：计划应完成 60% → 实际仅完成 50%；实际花费 \(AC = 60\) 万元。

**步骤 1：求三值**
- \(PV = BAC \times 计划完成\% = 100 \times 60\% = 60\) 万
- \(EV = BAC \times 实际完成\% = 100 \times 50\% = 50\) 万
- \(AC = 60\) 万

**步骤 2：偏差与指数**
- \(CV = EV - AC = 50 - 60 = -10\)（成本超支）
- \(SV = EV - PV = 50 - 60 = -10\)（进度落后）
- \(CPI = EV/AC = 50/60 \approx 0.83\)（<1 超支）
- \(SPI = EV/PV = 50/60 \approx 0.83\)（<1 落后）

**步骤 3：状态结论**：成本超支且进度落后，需纠偏。完整的三情形 EAC 计算与网络图、PERT 分步例题见各子专题。

## 四、易错点

- CV/CPI 看成本，SV/SPI 看进度，二者不可混。
- "ETC 按当前绩效"用 \(ETC = (BAC - EV)/CPI\)，非兜底式 \(EAC - AC\) 的误用。
- 关键路径可能随赶工而转移，压缩后须重算。
