## 一、概念与定位

**《招标投标法》** 规范境内所有"必须进行招标"的工程建设与采购活动，是 IT 系统集成项目获取合同最核心的法律依据之一，上午题每年必考单选（规模标准、时限、评标委员会、废标情形）。**《政府采购法》** 规范国家机关、事业单位、团体组织使用财政性资金采购货物、工程和服务，其采购方式与招投标法既有交叉又有差异，常以对比题出现。

在下午案例分析中，"违法分包/转包""未招标即签约""合同条款与招标不一致"等也是高频找错点，因此本节是上午、下午联动板块。

## 二、核心知识

### 1. 必须招标的规模标准（重点掌握，以最新法条为准）

达到以下任一标准**必须招标**：

| 采购对象 | 规模标准 |
|---|---|
| 施工（工程） | 单项合同估算价 ≥ **400 万元** |
| 货物（重要设备、材料等） | 单项合同估算价 ≥ **200 万元** |
| 服务（勘察、设计、监理等） | 单项合同估算价 ≥ **100 万元** |
| 项目总投资 | ≥ **3000 万元**（上述单项未达标但总投资达标的，也必须招标） |

### 2. 招标方式

- **公开招标**：发布招标公告，不指定投标人，竞争最充分，是政府采购的"主要方式"。
- **邀请招标**：向 **≥3 个**具备能力的特定法人/组织发出邀请；适用于技术复杂、有特殊要求或受自然环境限制、少量潜在投标人可供选择等情形。

### 3. 法定程序与关键时限（务必记牢）

| 环节 | 时限 / 要求 |
|---|---|
| 招标文件发售期 | ≥ **5 日** |
| 招标文件发出 → 投标截止 | ≥ **20 日** |
| 澄清 / 修改通知 | 投标截止 **≥15 日前**；不足则顺延截止时间 |
| 评标委员会 | **≥5 人单数**，技术经济专家 **≥2/3**；名单中标结果确定前保密 |
| 中标候选人公示 | 依法公示 |
| 中标通知书 → 签约 | 发出中标通知书后 **30 日内** 订立合同 |

### 4. 废标与否决投标情形

- **应当重新招标（废标）**：投标人少于 **3 个**；所有投标被否决。
- **否决投标（按废标处理）**：投标文件未按要求密封/签署、无单位盖章/法定代表人签字、联合体未附共同投标协议、串通投标、以他人名义投标（挂靠）、报价低于成本且无合理说明等。
- **中标人义务**：不得将**主体、关键性工作**分包；分包须征得招标人同意，且不得再次分包；**禁止转包**。

### 5. 政府采购五种方式对比

| 方式 | 适用情形 |
|---|---|
| 公开招标 | 主要方式，达限额标准货物/服务/工程一般公开招标 |
| 邀请招标 | 具有特殊性只能从有限范围供应商处采购；公开招标费用占项目总价值比例过大 |
| 竞争性谈判 | 招标后无供应商投标/无合格标；技术复杂不能确定详细规格；时间紧急不能等招标 |
| 单一来源 | 只能从唯一供应商采购；不可预见紧急情况不能从其他处采购；添购（原合同金额≤10%） |
| 询价 | 货物规格标准统一、现货货源充足且价格变化小 |

## 三、方法 / 流程（答题套路）

**招投标法定程序记忆链**：编制招标文件 → 公告/邀请 → 发售（≥5日）→ 澄清修改（≥15日前）→ 投标（截止≥20日）→ 开标 → 评标（委员会≥5人单数）→ 中标公示 → 发中标通知书 → **30日内签约**。

**对比题套路**：看到"政府采购"先判断方式，再套对应情形；看到"总投资 3000 万"立即联想到必须招标兜底条款。

---

## 四、易错点（高频坑）

- 把"文件发售≥5日"与"发至截止≥20日"记反，或漏掉"澄清≥15日前"。
- 评标委员会记成"≥3人""专家≥1/2"，正确为 **≥5人单数、专家≥2/3**。
- 必须招标四数字张冠李戴：施工 400、货物 200、服务 100、总投资 3000。
- 误认为"中标后随时签约"，实为 **30 日内**。
- 混淆"分包"（经同意、非主体）与"转包/违法分包"（禁止）。
- 政府采购"单一来源"误用于普通竞争情形，实际仅限唯一/紧急/添购。

## 五、真题自测 / 演练

**题 1（单选）**：某政府采购项目货物预算 180 万元，未达到公开招标限额。采购人可采用的方式不包括（ ）。
A. 竞争性谈判  B. 单一来源  C. 公开招标  D. 必须强制公开招标且不得采用其他方式
> 答案：D。未达公开招标限额的可依法采用其他采购方式，公开招标是主要方式而非唯一。

**题 2（单选）**：关于评标委员会，下列说法符合规定的是（ ）。
A. 成员 4 人  B. 专家占 1/2  C. 5 人以上单数、专家≥2/3  D. 名单开标前公示
> 答案：C。

**题 3（判断）**：某项目施工合同估算价 380 万元、设备采购 260 万元，因施工未达标故整个项目无需招标。
> 答案：错误。设备采购 260 万元 ≥200 万，须招标；总投资若≥3000 万同样须招标。

### 自测清单

- [ ] 必须招标四规模标准（400/200/100/3000 万）及对应对象
- [ ] 公开招标 vs 邀请招标（≥3 家）
- [ ] 三关键时限（发售≥5日、截止≥20日、澄清≥15日前、签约30日）
- [ ] 评标委员会（≥5人单数、专家≥2/3）
- [ ] 废标/重新招标（投标人<3）、否决投标情形
- [ ] 中标人不得转包、主体关键工作不得分包
- [ ] 政府采购五种方式及单一来源三类适用
- [ ] 区分《招标投标法》与《政府采购法》适用主体
