## 一、项目采购管理（Procurement）

过程：规划采购管理 → 实施采购 → 控制采购 → 结束采购。

- **规划采购**：自造或外购分析（Make-or-Buy）、合同类型选择、采购文件（RFP/RFQ）。
- **实施采购**：招标/投标（见[招投标](lx-zhaotoubiao.html)）、评标、签合同。
- **控制采购**：合同履约监督、变更、索赔、绩效审查。

## 二、合同类型（必考）

详见子专题[采购管理](ch-caigou.html)。按风险分担：

| 类型 | 风险承担 | 适用 |
|---|---|---|
| 总价合同 FFP/FP | 卖方 | 范围明确 |
| ├ 固定总价 FFP | 卖方 | 最确定 |
| ├ 总价加激励 FPIF | 共担 | 范围较明确 |
| └ 总价加经济价格调整 FP-EPA | 卖方（通胀保护） | 长期 |
| 成本补偿 CPFF/CPF/CPPC | 买方 | 范围不明 |
| ├ 成本+固定费用 CPFF | 买方 | 鼓励控本 |
| └ 成本+百分比费用 CPF | 买方（易超支） | 少用 |
| 工料合同 T&M | 混合 | 量不确定、短小 |

> **易错点**：范围明确选总价（卖方担风险），范围不清选成本补偿（买方担风险）；工料合同兼具两者特点。CPPC（成本+百分比）易鼓励超支，最不受欢迎。

## 三、合同管理（Contract）

详见子专题[合同管理](ch-hetong.html)。

- **合同要素**：标的、数量质量、价款、履行期限地点方式、违约责任、争议解决。
- **合同生命周期**：合同拟定→签订→履行→变更→终止/收尾。
- **合同变更**：须书面、双方协商一致；重大变更可能重新招标。
- **索赔管理**：索赔通知（28 日内）、索赔报告、监理/仲裁；反索赔。
- **合同收尾**：验收、结算、资料归档。

> **易错点**：索赔时效通常 28 天；合同变更必须书面；分包须发包人同意，主体工程不得分包，禁止转包。
