## 一、概念与定位

采购与合同管理解决"买什么、怎么买、签什么合同、如何履约与索赔"。在软考中级中：

- **上午综合知识**：合同类型（总价/成本补偿/工料）的风险归属与适用场景是单选必考；合同要素、索赔时效、分包规则也常考。
- **下午案例分析**：常出现"合同类型选错、口头变更、索赔超期、违法分包"等找错题，约占 15 分。

重点掌握：三类合同风险分担、合同变更须书面、索赔 28 天、主体不得分包。

## 二、核心知识

### （一）采购管理过程

规划采购管理 → 实施采购 → 控制采购 → 结束采购。

- **规划**：自制或外购分析（Make-or-Buy）、合同类型选择、采购文件（RFP/RFQ/IFB）。
- **实施**：招标/投标（公开招标、邀请招标）、评标、签合同。
- **控制**：履约监督、合同变更、索赔、绩效审查。
- **结束**：验收、结算、资料归档。

### （二）合同类型（必考，详见[采购子专题](ch-caigou.html)）

| 大类 | 子类 | 风险承担 | 适用 |
|---|---|---|---|
| 总价合同 | 固定总价 FFP | 卖方 | 范围明确、最确定 |
| | 总价加激励 FPIF | 共担 | 范围较明确 |
| | 总价加经济价格调整 FP-EPA | 卖方（通胀保护） | 长期 |
| 成本补偿 | 成本+固定费用 CPFF | 买方 | 鼓励控本 |
| | 成本+激励费 CPIF | 共担 | 范围不清 |
| | 成本+奖励费 CPAF | 买方 | 主观评价 |
| 工料 T&M | — | 混合 | 量不确定、短期 |

### （三）合同管理（详见[合同子专题](ch-hetong.html)）

- **合同要素**：标的、数量质量、价款、履行期限/地点/方式、违约责任、争议解决。
- **生命周期**：拟定 → 签订 → 履行 → 变更 → 终止/收尾。
- **变更**：须书面、双方协商一致；重大变更可能重新招标。
- **索赔**：通知通常 28 日内，附报告；监理/仲裁处理；相对方有反索赔权。
- **分包**：须经发包人同意；**主体工程不得分包**；**禁止转包**。

## 三、方法/流程

合同类型选择方法：范围明确 → 总价（卖方担风险）；范围不清 → 成本补偿（买方担风险）；工作量难估、短期 → 工料。索赔流程：事态调查→索赔通知(28天)→提交报告→对方答复→协商/调解/仲裁→反索赔。

## 四、记忆口诀/易错点

- **合同类型口诀**："范围明、选总价，卖方担风险；范围糊、选成本，买方担风险；量不定、用工料，风险混合担"。
- **易错**：CPFF（成本+固定费用）对买方风险大但鼓励卖方控本；CPPC（成本+百分比费用）易鼓励超支，最不受欢迎。
- **易错**：合同变更必须**书面**；"口头同意"无效。
- **易错**：索赔时效通常 **28 天**，逾期可能失权。
- **易错**：主体工程不得分包、禁止转包；分包须发包人同意。
