## 一、分层模型

**OSI 七层**（物→数→网→传→会→表→应）为理论模型；**TCP/IP 四层**（网络接口→网际→传输→应用）为实用模型。考试常考各层功能与设备归属：

| 层 | 典型设备/协议 |
|---|---|
| 物理层 | 中继器、集线器、双绞线 |
| 数据链路层 | 交换机、网桥、MAC |
| 网络层 | 路由器、IP、ICMP |
| 传输层 | TCP、UDP |
| 应用层 | HTTP、FTP、DNS、SMTP |

## 二、IP 地址与子网划分（计算常考）

- IPv4 为 32 位，点分十进制；A（1–126）、B（128–191）、C（192–223）。
- **子网掩码**区分网络位与主机位；CIDR 形如 `/24`。
- 主机数 = `2^(主机位数) − 2`（去掉网络地址与广播地址）。
- 子网数 = `2^(借位数)`。

> **示例**：`192.168.1.0/26`，主机位 = 32−26 = 6，每子网主机数 = 2⁶−2 = 62，可划 4 个子网。

## 三、TCP vs UDP

| | TCP | UDP |
|---|---|---|
| 连接 | 面向连接 | 无连接 |
| 可靠 | 是（确认/重传） | 否 |
| 速度 | 较慢 | 快 |
| 应用 | HTTP、FTP、SMTP | DNS、视频、语音 |

TCP 三次握手（SYN→SYN+ACK→ACK）建立连接，四次挥手断开。

## 四、网络设计

三层架构：**核心层**（高速转发）、**汇聚层**（策略/路由聚合）、**接入层**（用户接入）。冗余设计提升可用性。
