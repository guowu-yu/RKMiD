## 一、概念与定位

网络技术是软考上午**稳定考点**（约 5–8 分），子网划分计算、OSI/TCP-IP 分层、协议端口是经典题型；下午案例也常考网络规划（核心/汇聚/接入三层）。务必动手算子网、背端口，属"会算即得分"型。

## 二、核心知识

### 1. 分层模型

**OSI 七层**（物→数→网→传→会→表→应）为理论模型；**TCP/IP 四层**（网络接口→网际→传输→应用）为实用模型。各层设备/协议：

| 层 | 典型设备 / 协议 |
|---|---|
| 物理层 | 中继器、集线器、双绞线 |
| 数据链路层 | 交换机、网桥、MAC |
| 网络层 | 路由器、IP、ICMP |
| 传输层 | TCP、UDP |
| 应用层 | HTTP、FTP、DNS、SMTP |

### 2. IP 地址与子网划分（计算常考）

IPv4 为 32 位点分十进制：**A 类 1–126**（默认 /8）、**B 类 128–191**（/16）、**C 类 192–223**（/24）；D 类 224–239 组播，E 类 240–255 保留。

- **主机数** = \(2^{主机位}-2\)（去掉网络地址与广播地址）
- **子网数** = \(2^{借位数}\)
- CIDR 如 `/26` 表示前 26 位为网络位。

> **示例**：`192.168.1.0/26`，主机位 = 32−26 = 6，每子网主机数 = \(2^6-2 = 62\)，可划 \(2^{26-24}=4\) 个子网。

### 3. TCP vs UDP

| | TCP | UDP |
|---|---|---|
| 连接 | 面向连接 | 无连接 |
| 可靠 | 是（确认/重传） | 否 |
| 速度 | 较慢 | 快 |
| 应用 | HTTP、FTP、SMTP | DNS、视频、语音 |

TCP **三次握手**（SYN→SYN+ACK→ACK）建立连接，**四次挥手**断开。常见端口：HTTP 80 / HTTPS 443 / FTP 20,21 / DNS 53 / SMTP 25 / POP3 110 / SSH 22 / Telnet 23。

### 4. 网络三层设计

**核心层**（高速转发）、**汇聚层**（策略/路由聚合）、**接入层**（用户接入）；冗余与负载均衡提升可用性。

## 三、方法/要点（子网划分流程）

①看 IP 类别定默认掩码；②按 CIDR/新掩码算网络位与主机位；③主机数=\(2^{主机位}-2\)；④网络号=IP 与掩码按位与；⑤判断某 IP 所属子网看网络号是否相同。

## 四、记忆口诀/易错点

> **OSI 层序口诀**："应（7）表（6）会（5）传（4）网（3）数（2）物（1）"，或反背"物数网传会表应"。

> **易错点**：①主机数要减 2；②A 类不含 0 和 127；③"交换机"是数据链路层、"路由器"是网络层；④TCP 三次握手建连、UDP 无连接；⑤HTTP 端口 80、HTTPS 443 易混。

## 五、真题自测

1. （单选）工作在数据链路层、用于局域网内帧转发的设备是（ ）。
   A. 路由器  B. 交换机  C. 中继器  D. 集线器

2. （计算）IP 地址 `192.168.1.0/27`，每个子网可用主机数为（ ）。
   A. 30  B. 32  C. 62  D. 14

3. （多选）下列属于 TCP 特性的是（ ）。
   A. 面向连接  B. 可靠传输  C. 无连接  D. 有流量控制

> **参考答案**：1. B；2. A（主机位=32−27=5，\(2^5-2=30\)）；3. ABD。
