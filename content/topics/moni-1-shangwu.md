75. EVM is an abbreviation for（ ）.
    A. Earned Value Management
    B. Expected Variance Method
    C. Early Value Measurement
    D. Estimated Volume Model

---

> **参考答案**
>
> 1-10: A C B D C D D B A B
> 11-20: D B D A B D D B D C
> 21-30: D B B C B C D B C B
> 31-40: B B D A C C A B B A
> 41-50: B B B A B B B A B A
> 51-60: B B B C D D A B D A
> 61-70: D C C B C D B B B C
> 71-75: C B A B A

**简要解析**

1. 智慧城市参考模型自下而上为：物联感知层、网络通信层、计算与存储层、数据及服务支撑层、智慧应用层，最底层是物联感知层。
2. G2C（Government to Citizen）即政府对公民。
3. ERP 整合企业内部人财物，实现产供销一体化；CRM 管客户、SCM 管供应链。
4. 大数据 4V：Volume、Velocity、Variety、Value，无"Virtual"。
5. SaaS 提供现成应用，用户无需管理底层；IaaS 用户管 OS 及以上，PaaS 管应用及以上。
6. ITSS 运维能力四要素：人员、过程、技术、资源，无"资金"。
7. 信息系统生命周期四阶段：立项、开发、运维、消亡。
8. 等保 2.0 第三级及以上每年测评一次。
9. 信息安全三性：保密性、完整性、可用性（CIA）。
10. 物联网三层：感知层、网络层、应用层。
11. 区块链去中心化，无中央机构统一记账。
12. 中间件屏蔽异构平台差异，位于 OS 与应用间。
13. 敏捷四条价值观均强调"高于"后者，响应变化高于遵循计划正确。
14. 数字孪生即物理实体与虚拟模型实时映射。
