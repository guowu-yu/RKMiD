## 一、概念与定位

上午基础知识题固定含 **5 道英文题（约 5 分）**，全部来自项目管理与 IT 英语，核心是 **PMBOK 十大知识领域**术语和部分 IT 技术词汇。属于"背熟即得分"的送分区——不必逐词翻译，抓术语与句式结构即可。

---

## 二、核心知识

### 1. 十大知识领域英文名（必背）

| 中文 | 英文 |
|---|---|
| 整合管理 | Integration Management |
| 范围管理 | Scope Management |
| 进度管理 | Schedule Management |
| 成本管理 | Cost Management |
| 质量管理 | Quality Management |
| 资源管理 | Resource Management |
| 沟通管理 | Communication Management |
| 风险管理 | Risk Management |
| 采购管理 | Procurement Management |
| 干系人管理 | Stakeholder Management |

### 2. 高频术语中英对照

| 术语 | 英文 | 含义 |
|---|---|---|
| 项目章程 | Project Charter | 正式授权项目成立的文件 |
| 工作分解结构 | WBS (Work Breakdown Structure) | 将可交付成果分解为工作包 |
| 基线 | Baseline | 经批准的范围/进度/成本基准 |
| 可交付成果 | Deliverable | 项目产出物 |
| 关键路径 | Critical Path | 总工期最长的活动路径 |
| 浮动时间 | Float / Slack | 活动可延误而不影响总工期的机动时间 |
| 里程碑 | Milestone | 零工期的标志性事件 |
| 挣值 | Earned Value (EV) | 实际完成工作的预算值 |
| 计划价值 | Planned Value (PV) | 计划完成工作的预算值 |
| 实际成本 | Actual Cost (AC) | 实际发生的成本 |
| 成本偏差 | Cost Variance (CV) | CV = EV − AC |
| 进度偏差 | Schedule Variance (SV) | SV = EV − PV |
| 成本绩效指数 | CPI | CPI = EV / AC |
| 进度绩效指数 | SPI | SPI = EV / PV |
| 风险 | Risk | 不确定事件对目标的影响 |
| 干系人 | Stakeholder | 影响或被项目影响的个人或组织 |
| 采购 | Procurement | 从外部获取产品/服务 |
| 合同 | Contract | 具法律约束的协议 |

### 3. 常见句式（抓结构即可）

- **"The process of ______ is to..."** → 描述某个过程的目的（如 "The process of Define Scope is to develop a detailed description of the project..."）。
- **"______ is the approved version of..."** → 定义"基线"类概念。
- 题干常是某概念的英文定义，要求选出对应中文术语，或反之。

---

## 三、方法 / 流程（答题套路）

1. **先看术语**：遇到大写缩写（WBS/EVM/PV/EV/AC/CPI/SPI）直接定位知识领域。
2. **再看句式主语+动词**：判断是"定义过程"还是"描述输出"。
3. **排除法**：用 IT 常识排除明显无关选项；遇到生词结合构词法（如 *manage / plan / control* 词根）。
4. **重点记忆**：十大领域英文名 + 挣值四值四指标英文 + Critical Path / Baseline / Deliverable / Stakeholder。

---

## 四、易错点（高频坑）

- 把 **PV（计划价值）** 与 **EV（挣值）** 英文含义记反。
- 混淆 **CPI（成本）** 与 **SPI（进度）** 的分子分母。
- 漏背十大领域英文，导致整句无法定位。
- 想逐词翻译而犹豫，耽误时间——英语题应"秒杀"。

## 五、真题自测 / 演练

**题 1（英译中）**："The *Critical Path* is the sequence of activities that determines the **longest** duration of the project."
> 答案：关键路径是决定项目总工期最长的活动序列。

**题 2（中译英选择）**："成本绩效指数小于 1 表示成本超支"，其英文缩写与含义是（ ）。
A. SPI<1 进度落后  B. CPI<1 成本超支  C. CV<0 成本超支  D. B 和 C 都正确
> 答案：D。CPI<1、CV<0 均表示成本超支。

**题 3（术语）**：WBS 的全称与中文是（ ）。
A. Work Breakdown Structure / 工作分解结构  B. Wide Band System / 宽带系统  C. Web Base System / 网站系统
> 答案：A。
